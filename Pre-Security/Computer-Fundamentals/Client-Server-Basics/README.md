## Overview

This room introduces the fundamentals of client-server communication and provides practical experience with HTTP requests and responses.

The room covers how a client communicates with a server, HTTP methods, and how web browsers send requests when accessing a website. It also provides hands-on practice inspecting HTTP traffic using browser Developer Tools.

## Tools Used

- Firefox Developer Tools
- Network panel

## Approach

1. Started the TryHackMe Lab Machine.
2. Opened the provided HTTP demo website in Firefox.
3. Opened Firefox Developer Tools and navigated to the Network panel.
4. Reloaded the webpage to capture the HTTP requests generated by the browser.
5. Selected the main `GET /` request to inspect its details.
6. Examined the request headers, including the scheme, host, filename, address, and HTTP status.
7. Opened the Response tab to inspect the HTML content returned by the web server.

## Result

Successfully inspected an HTTP GET request and its response using Firefox Developer Tools.

The request was identified as a `GET` request using the `http` scheme, with `httpdemo.local:8080` as the host and `/` as the requested filename. The request returned a `200 OK` status, and the response body contained the HTML returned by the web server.

## Key Takeaways

- HTTP is used for communication between a client and a web server.
- The `GET` method is used to request a resource from a web server.
- Browser Developer Tools can be used to inspect HTTP requests and responses.
- The Network panel provides information about requests made by a web browser.
- HTTP request information includes fields such as the scheme, host, filename, address, and status.
- An HTTP response contains response headers and a response body.
