## Overview

This room introduces the fundamentals of client-server communication and web communication using HTTP.

The room covers HTTP methods and provides hands-on practice inspecting HTTP requests and responses using a web browser and Developer Tools.

## Tools Used

- Firefox
- Firefox Developer Tools
- Network panel
- TryHackMe Lab Machine

## Approach

1. Started the TryHackMe Lab Machine.
2. Opened the provided HTTP demonstration website in Firefox.
3. Opened Firefox Developer Tools and navigated to the Network panel.
4. Reloaded the webpage to capture the HTTP requests generated by the browser.
5. Selected the main `GET /` request and inspected its headers.

![HTTP GET Request Headers](http-get-request-headers.png)

6. Inspected the request details, including the scheme, host, filename, address, HTTP version, and status code.
7. Opened the Response tab to inspect the HTML content returned by the server.

![HTTP Response Body](http-response-body.png)

8. Practiced identifying the host and scheme from a URL.

## Result

Successfully inspected an HTTP `GET` request and its response using Firefox Developer Tools.

The request was identified as a `GET` request using the `http` scheme, with `httpdemo.local:8080` as the host and `/` as the requested filename. The request returned a `200 OK` status, and the response body contained the HTML returned by the web server.

## Key Takeaways

- HTTP is used for communication between a client and a web server.
- The `GET` method is used to retrieve a resource from a server.
- Firefox Developer Tools can be used to inspect HTTP requests and responses.
- The Network panel provides information about requests made by a browser.
- Request details include information such as the scheme, host, filename, address, and status.
- An HTTP response contains information returned by the server, including the response body.
